Offline reading list

How it works

Everything here is a text copy: web articles you opened in the reading view and deliberately saved, and the articles and .epub files you imported with Import below. They all open without a connection and stay on your device, even if the original page goes away.

Import and export (articles or EPUB)

    Import and export

    Import reads the file it is given: a backup of the re/read article list (.json), or an e-book (.epub).

    File format

    .json - a backup file holding every article saved in the re/read offline reading list, from this browser or any other browser or device where you use re/read. Import only adds the articles missing here and never overwrites one already saved.

    .epub - the e-book format.

    Export covers articles only - books (.epub) are not exported. Importing a book again brings everything back except the reading position.

    Export highlights writes a plain-text .md file of your highlighted passages, grouped by document - made for notes, not for import. Highlights travel between devices inside the article list's .json backup.
