Translation models

A model is what turns one language into another, and there is one per direction. Nothing is translated until the model for the pair you are reading is here, on this device.

Downloading a model is the only time this extension uses the network, and it is the only request it will ever make. The files come from -, where Mozilla publishes them, at addresses written down in this package. Every file is checked against a checksum that was recorded here on -: anything that does not match is thrown away rather than stored. Nothing about you is sent - the request says which model, and nothing else.

Add a model from files

Pick the three files of one direction and they are stored locally. Gzipped files are unpacked here, so the downloads can be used as they come:

  • model.enpl.intgemm.alphas.bin
  • lex.50.50.enpl.s2t.bin
  • vocab.enpl.spm

This page stays even once models download themselves: it is the way out on the day the place they are downloaded from stops answering. Nothing here leaves the device, and adding a model makes no network request at all.
